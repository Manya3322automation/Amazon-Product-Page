# Amazon Book Product Page

A simple Amazon-inspired book product page built using HTML and CSS as part of my web development learning journey.

## Features
- Book cover and product information layout
- Flexbox for arranging content
- CSS styling for spacing and alignment
- Book ratings and author information

## Technologies Used
- HTML5
- CSS3

## Purpose
This project helped me practice HTML structure, CSS styling, and Flexbox by recreating a book product page inspired by Amazon.
